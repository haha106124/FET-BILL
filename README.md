# AI 工地辨識助手

用電腦管理電話表、用手機後鏡頭掃描遠傳帳單信封上的收件人姓名，快速找到所屬工地。

## 已包含功能

- 姓名、電話、簡碼與工地的容錯搜尋
- 手機後鏡頭即時掃描、相簿辨識
- 同名或相近姓名的候選結果
- PWA：可加入手機主畫面並快取 OCR 引擎
- 加密電話表：明文 Excel、PDF、JSON 一律不提交到 GitHub

## 資料安全

程式碼可部署，但電話表必須先在電腦端加密成 `data/directory.enc.json`。GitHub 只會保存加密後的資料；帳號與密碼不會寫入程式或 Git 紀錄。

目前沒有提交任何電話名冊、PDF、Excel 或加密資料。電話表設定完成後，手機才會顯示可查詢的工地資料。

## 手機使用

GitHub Pages 開啟後，用手機以 HTTPS 網址進入，允許相機權限並選擇「相機掃描」。可從瀏覽器選單將網站加入主畫面。
